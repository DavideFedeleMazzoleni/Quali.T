# Quali.T
Quali.T è un'applicazione mobile per la scoperta dei migliori prodotti locali nella città di Trento. Quali.T permette di cercare prodotti, trovare chi li vende e prenotarli per il ritiro.

## Stack
- **Backend**: Node.js, Express 5, MariaDB, JWT
- **Frontend**: Flutter, Vue.js
- **Test**: Jest, Supertest
